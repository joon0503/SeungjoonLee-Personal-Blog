## Rotary positional embedding (RoPE)

{/* Derivation: rotate query/key pairs by angle m·θ_i so that q_mᵀ k_n depends only on (m − n).
    2D rotation view and complex-number view. Applied to q, k (not v), in every layer.
    Long-term decay; base frequency; context extension (position interpolation, NTK-aware scaling, YaRN). */}
